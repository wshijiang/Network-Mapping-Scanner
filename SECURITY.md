# Security Policy

## Supported Versions

我们通常只接收最新版本的漏洞报告，且当前只会维护一个新版本。

We generally only accept vulnerability reports affecting the latest version of the project. Currently, we maintain only the latest release.

| Version | Supported          |
| ------- | ------------------ |
| 最新  | :white_check_mark: |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

各位支持者，若发现项目存在安全漏洞，烦请前往 security 页面报告，请不要在任何PR或者issue中报告。

if you discover a security vulnerability in this project, please report it privately through the Security page on GitHub. Do not report security vulnerabilities through public Pull Requests or Issues.

我们在收到漏洞报告后，通常会在24小时内确认，并在5天内评估。

We typically acknowledge vulnerability reports within 24 hours of receiving them and complete an initial assessment within 5 days.

我们感谢您负责任地披露漏洞，并为本项目的安全做出贡献！

We sincerely appreciate your responsible disclosure of security vulnerabilities and your contributions to keeping this project secure!
